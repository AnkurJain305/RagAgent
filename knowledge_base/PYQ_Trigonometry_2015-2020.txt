## Trigonometric Ratios and Identities

### Question 1 (JEE Main 2015)

**Question:** If $\sin\theta + \sin^2\theta = 1$, then the value of $\cos^4\theta - \cos^2\theta$ is

**Solution:**
Step 1: Given that $\sin\theta + \sin^2\theta = 1$.

Step 2: Rearranging, we get $\sin\theta = 1 - \sin^2\theta$.

Step 3: Using the identity $\sin^2\theta + \cos^2\theta = 1$, we can write $\sin^2\theta = 1 - \cos^2\theta$.

Step 4: Substituting this into the equation from Step 2, we get:
$\sin\theta = 1 - (1 - \cos^2\theta) = \cos^2\theta$.

Step 5: Now, we need to find the value of $\cos^4\theta - \cos^2\theta$.

Step 6: Using the result from Step 4, we have $\sin\theta = \cos^2\theta$.

Step 7: Squaring both sides, we get $\sin^2\theta = \cos^4\theta$.

Step 8: Using the identity $\sin^2\theta = 1 - \cos^2\theta$ again, we have:
$1 - \cos^2\theta = \cos^4\theta$

Step 9: Rearranging, we get:
$\cos^4\theta + \cos^2\theta = 1$

Step 10: Therefore, $\cos^4\theta - \cos^2\theta = 1 - 2\cos^2\theta$.

Step 11: From Step 4, we know that $\sin\theta = \cos^2\theta$. Substituting this into the original equation, we get:
$\cos^2\theta + (\cos^2\theta)^2 = 1$
$\cos^2\theta + \cos^4\theta = 1$

Step 12: From this, we can directly say that $\cos^4\theta - \cos^2\theta = -2\cos^2\theta + 1$.

Step 13: To find the value of $\cos^2\theta$, we can use the equation from Step 11:
$\cos^2\theta + \cos^4\theta = 1$

Step 14: Let $x = \cos^2\theta$. Then, the equation becomes:
$x + x^2 = 1$
$x^2 + x - 1 = 0$

Step 15: Using the quadratic formula, we get:
$x = \frac{-1 \pm \sqrt{1 + 4}}{2} = \frac{-1 \pm \sqrt{5}}{2}$

Step 16: Since $\cos^2\theta$ is always non-negative, we take the positive value:
$\cos^2\theta = \frac{-1 + \sqrt{5}}{2}$

Step 17: Substituting this into the expression $\cos^4\theta - \cos^2\theta$, we get:
$\cos^4\theta - \cos^2\theta = (\cos^2\theta)^2 - \cos^2\theta = (\frac{-1 + \sqrt{5}}{2})^2 - \frac{-1 + \sqrt{5}}{2}$

Step 18: Simplifying, we get:
$\cos^4\theta - \cos^2\theta = \frac{(\sqrt{5} - 1)^2}{4} - \frac{\sqrt{5} - 1}{2}$
$= \frac{5 - 2\sqrt{5} + 1}{4} - \frac{2\sqrt{5} - 2}{4}$
$= \frac{6 - 2\sqrt{5} - 2\sqrt{5} + 2}{4}$
$= \frac{8 - 4\sqrt{5}}{4}$
$= 2 - \sqrt{5}$

Therefore, the value of $\cos^4\theta - \cos^2\theta$ is $2 - \sqrt{5}$.

### Question 2 (JEE Advanced 2016)

**Question:** If $\sin\alpha + \sin\beta = a$ and $\cos\alpha + \cos\beta = b$, then the value of $\sin(\alpha + \beta)$ is

**Solution:**
Step 1: We know that $\sin\alpha + \sin\beta = a$ and $\cos\alpha + \cos\beta = b$.

Step 2: Using the trigonometric identities:
$\sin\alpha + \sin\beta = 2\sin\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2}$
$\cos\alpha + \cos\beta = 2\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2}$

Step 3: From the given conditions, we have:
$2\sin\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2} = a$
$2\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2} = b$

Step 4: Dividing the first equation by the second, we get:
$\frac{\sin\frac{\alpha + \beta}{2}}{\cos\frac{\alpha + \beta}{2}} = \frac{a}{b}$
$\tan\frac{\alpha + \beta}{2} = \frac{a}{b}$

Step 5: Now, we need to find $\sin(\alpha + \beta)$. Using the double angle formula, we have:
$\sin(\alpha + \beta) = 2\sin\frac{\alpha + \beta}{2}\cos\frac{\alpha + \beta}{2}$

Step 6: We know that $\tan\frac{\alpha + \beta}{2} = \frac{a}{b}$, which means $\sin\frac{\alpha + \beta}{2} = \frac{a}{\sqrt{a^2 + b^2}}$ and $\cos\frac{\alpha + \beta}{2} = \frac{b}{\sqrt{a^2 + b^2}}$.

Step 7: Substituting these values into the expression for $\sin(\alpha + \beta)$, we get:
$\sin(\alpha + \beta) = 2 \cdot \frac{a}{\sqrt{a^2 + b^2}} \cdot \frac{b}{\sqrt{a^2 + b^2}} = \frac{2ab}{a^2 + b^2}$

Therefore, the value of $\sin(\alpha + \beta)$ is $\frac{2ab}{a^2 + b^2}$.

### Question 3 (JEE Main 2017)

**Question:** If $\sin\theta + \cos\theta = \sqrt{2}\cos(\frac{\pi}{4} - \theta)$, then the value of $\theta$ is

**Solution:**
Step 1: We need to simplify the right-hand side of the equation first.

Step 2: Using the angle subtraction formula for cosine, we have:
$\cos(\frac{\pi}{4} - \theta) = \cos\frac{\pi}{4}\cos\theta + \sin\frac{\pi}{4}\sin\theta$

Step 3: We know that $\cos\frac{\pi}{4} = \sin\frac{\pi}{4} = \frac{1}{\sqrt{2}}$. Substituting these values, we get:
$\cos(\frac{\pi}{4} - \theta) = \frac{1}{\sqrt{2}}\cos\theta + \frac{1}{\sqrt{2}}\sin\theta = \frac{1}{\sqrt{2}}(\cos\theta + \sin\theta)$

Step 4: Now, the original equation becomes:
$\sin\theta + \cos\theta = \sqrt{2} \cdot \frac{1}{\sqrt{2}}(\cos\theta + \sin\theta)$
$\sin\theta + \cos\theta = \cos\theta + \sin\theta$

Step 5: This equation is an identity, which means it is true for all values of $\theta$.

Therefore, the value of $\theta$ can be any real number.

### Question 4 (JEE Advanced 2018)

**Question:** If $\sin\alpha + \sin\beta + \sin\gamma = 3$ and $\cos\alpha + \cos\beta + \cos\gamma = 0$, where $0 \leq \alpha, \beta, \gamma \leq 2\pi$, then the value of $\sin(\alpha + \beta + \gamma)$ is

**Solution:**
Step 1: We know that $\sin\alpha + \sin\beta + \sin\gamma = 3$ and $\cos\alpha + \cos\beta + \cos\gamma = 0$.

Step 2: Let's define a complex number $z = e^{i\alpha} + e^{i\beta} + e^{i\gamma}$.

Step 3: The real part of $z$ is $\cos\alpha + \cos\beta + \cos\gamma = 0$.

Step 4: The imaginary part of $z$ is $\sin\alpha + \sin\beta + \sin\gamma = 3$.

Step 5: Therefore, $z = 0 + 3i = 3i$.

Step 6: Now, let's compute $z^3$:
$z^3 = (e^{i\alpha} + e^{i\beta} + e^{i\gamma})^3$

Step 7: Expanding this expression, we get terms like $e^{3i\alpha}$, $e^{2i\alpha + i\beta}$, etc. The coefficient of $e^{i(\alpha + \beta + \gamma)}$ in this expansion is 6.

Step 8: On the other hand, $z^3 = (3i)^3 = 27i^3 = 27 \cdot (-i) = -27i$.

Step 9: Therefore, $6e^{i(\alpha + \beta + \gamma)} + \text{other terms} = -27i$.

Step 10: This approach is getting complex. Let's try another method.

Step 11: Let's use the fact that $\sin\alpha + \sin\beta + \sin\gamma = 3$ and $\cos\alpha + \cos\beta + \cos\gamma = 0$.

Step 12: We know that $\sin(\alpha + \beta + \gamma) = \sin\alpha\cos\beta\cos\gamma + \cos\alpha\sin\beta\cos\gamma + \cos\alpha\cos\beta\sin\gamma - \sin\alpha\sin\beta\sin\gamma$.

Step 13: This approach is also getting complex. Let's try yet another method.

Step 14: Let's use the fact that $\sin\alpha + \sin\beta + \sin\gamma = 3$ and $\cos\alpha + \cos\beta + \cos\gamma = 0$.

Step 15: Since $\sin\alpha + \sin\beta + \sin\gamma = 3$ and the maximum value of sine is 1, we must have $\sin\alpha = \sin\beta = \sin\gamma = 1$.

Step 16: This means $\alpha = \beta = \gamma = \frac{\pi}{2}$.

Step 17: Checking the second condition, we have $\cos\alpha + \cos\beta + \cos\gamma = \cos\frac{\pi}{2} + \cos\frac{\pi}{2} + \cos\frac{\pi}{2} = 0 + 0 + 0 = 0$, which is satisfied.

Step 18: Therefore, $\sin(\alpha + \beta + \gamma) = \sin(\frac{3\pi}{2}) = -1$.

Therefore, the value of $\sin(\alpha + \beta + \gamma)$ is $-1$.

### Question 5 (JEE Main 2019)

**Question:** If $\sin\theta + \cos\theta = \sqrt{3}$, then the value of $\sin^3\theta + \cos^3\theta$ is

**Solution:**
Step 1: Given that $\sin\theta + \cos\theta = \sqrt{3}$.

Step 2: Squaring both sides, we get:
$(\sin\theta + \cos\theta)^2 = 3$
$\sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = 3$

Step 3: Using the identity $\sin^2\theta + \cos^2\theta = 1$, we get:
$1 + 2\sin\theta\cos\theta = 3$
$2\sin\theta\cos\theta = 2$
$\sin\theta\cos\theta = 1$

Step 4: Now, we need to find the value of $\sin^3\theta + \cos^3\theta$.

Step 5: We can use the identity $a^3 + b^3 = (a + b)^3 - 3ab(a + b)$.

Step 6: Applying this identity with $a = \sin\theta$ and $b = \cos\theta$, we get:
$\sin^3\theta + \cos^3\theta = (\sin\theta + \cos\theta)^3 - 3\sin\theta\cos\theta(\sin\theta + \cos\theta)$

Step 7: Substituting the given values, we get:
$\sin^3\theta + \cos^3\theta = (\sqrt{3})^3 - 3 \cdot 1 \cdot \sqrt{3}$
$= 3\sqrt{3} - 3\sqrt{3}$
$= 0$

Therefore, the value of $\sin^3\theta + \cos^3\theta$ is $0$.

### Question 6 (JEE Advanced 2020)

**Question:** If $\sin\alpha + \sin\beta = \frac{\sqrt{3}}{2}$ and $\cos\alpha + \cos\beta = \frac{1}{2}$, then the value of $\cos(\alpha - \beta)$ is

**Solution:**
Step 1: We know that $\sin\alpha + \sin\beta = \frac{\sqrt{3}}{2}$ and $\cos\alpha + \cos\beta = \frac{1}{2}$.

Step 2: Using the trigonometric identities:
$\sin\alpha + \sin\beta = 2\sin\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2}$
$\cos\alpha + \cos\beta = 2\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2}$

Step 3: From the given conditions, we have:
$2\sin\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2} = \frac{\sqrt{3}}{2}$
$2\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2} = \frac{1}{2}$

Step 4: Simplifying, we get:
$\sin\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2} = \frac{\sqrt{3}}{4}$
$\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2} = \frac{1}{4}$

Step 5: Dividing the first equation by the second, we get:
$\frac{\sin\frac{\alpha + \beta}{2}}{\cos\frac{\alpha + \beta}{2}} = \frac{\frac{\sqrt{3}}{4}}{\frac{1}{4}} = \sqrt{3}$
$\tan\frac{\alpha + \beta}{2} = \sqrt{3}$

Step 6: This means $\frac{\alpha + \beta}{2} = \frac{\pi}{3}$, so $\alpha + \beta = \frac{2\pi}{3}$.

Step 7: Now, let's find $\cos(\alpha - \beta)$. Using the identity $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$, we need to find $\sin\alpha\sin\beta$.

Step 8: We know that $(\sin\alpha + \sin\beta)^2 = \sin^2\alpha + 2\sin\alpha\sin\beta + \sin^2\beta$.

Step 9: Rearranging, we get:
$\sin\alpha\sin\beta = \frac{(\sin\alpha + \sin\beta)^2 - \sin^2\alpha - \sin^2\beta}{2}$

Step 10: Similarly, $(\cos\alpha + \cos\beta)^2 = \cos^2\alpha + 2\cos\alpha\cos\beta + \cos^2\beta$, which gives:
$\cos\alpha\cos\beta = \frac{(\cos\alpha + \cos\beta)^2 - \cos^2\alpha - \cos^2\beta}{2}$

Step 11: Using the identity $\sin^2\theta + \cos^2\theta = 1$, we have $\sin^2\alpha + \cos^2\alpha = 1$ and $\sin^2\beta + \cos^2\beta = 1$.

Step 12: Substituting these into the expressions for $\sin\alpha\sin\beta$ and $\cos\alpha\cos\beta$, we get:
$\sin\alpha\sin\beta = \frac{(\sin\alpha + \sin\beta)^2 - (1 - \cos^2\alpha) - (1 - \cos^2\beta)}{2}$
$= \frac{(\sin\alpha + \sin\beta)^2 - 2 + \cos^2\alpha + \cos^2\beta}{2}$

$\cos\alpha\cos\beta = \frac{(\cos\alpha + \cos\beta)^2 - (1 - \sin^2\alpha) - (1 - \sin^2\beta)}{2}$
$= \frac{(\cos\alpha + \cos\beta)^2 - 2 + \sin^2\alpha + \sin^2\beta}{2}$

Step 13: Adding these two equations, we get:
$\sin\alpha\sin\beta + \cos\alpha\cos\beta = \frac{(\sin\alpha + \sin\beta)^2 + (\cos\alpha + \cos\beta)^2 - 4 + 2}{2}$
$= \frac{(\sin\alpha + \sin\beta)^2 + (\cos\alpha + \cos\beta)^2 - 2}{2}$

Step 14: Substituting the given values, we get:
$\cos(\alpha - \beta) = \frac{(\frac{\sqrt{3}}{2})^2 + (\frac{1}{2})^2 - 2}{2}$
$= \frac{\frac{3}{4} + \frac{1}{4} - 2}{2}$
$= \frac{1 - 2}{2}$
$= -\frac{1}{2}$

Therefore, the value of $\cos(\alpha - \beta)$ is $-\frac{1}{2}$.

## Trigonometric Equations

### Question 7 (JEE Main 2015)

**Question:** The number of solutions of the equation $\sin^2 x - \sin x - 2 = 0$ in the interval $[0, 4\pi]$ is

**Solution:**
Step 1: Let's solve the equation $\sin^2 x - \sin x - 2 = 0$.

Step 2: This is a quadratic equation in $\sin x$. Let $y = \sin x$. Then, the equation becomes:
$y^2 - y - 2 = 0$

Step 3: Factoring this, we get:
$(y - 2)(y + 1) = 0$

Step 4: This gives $y = 2$ or $y = -1$.

Step 5: Since $y = \sin x$, we have $\sin x = 2$ or $\sin x = -1$.

Step 6: The maximum value of $\sin x$ is 1, so $\sin x = 2$ has no solutions.

Step 7: For $\sin x = -1$, we have $x = \frac{3\pi}{2} + 2n\pi$ or $x = \frac{7\pi}{2} + 2n\pi$, where $n$ is an integer.

Step 8: In the interval $[0, 4\pi]$, the solutions are $x = \frac{3\pi}{2}$, $x = \frac{7\pi}{2}$, and $x = \frac{11\pi}{2}$.

Therefore, the number of solutions of the equation $\sin^2 x - \sin x - 2 = 0$ in the interval $[0, 4\pi]$ is 3.

For $x = \frac{\pi}{2}$, we have $\sin^2 \frac{\pi}{2} + \sin^2 \pi = 1 + 0 = 1$, which is correct.

For $x = \frac{5\pi}{6}$, we have $\sin^2 \frac{5\pi}{6} + \sin^2 \frac{5\pi}{3} = \frac{1}{4} + \frac{3}{4} = 1$, which is correct.

### Question 13 (JEE Main 2015)

**Question:** The value of $\sin(\tan^{-1}\frac{1}{2} + \cot^{-1}2)$ is

**Solution:**
Step 1: Let's denote $\alpha = \tan^{-1}\frac{1}{2}$ and $\beta = \cot^{-1}2$.

Step 2: We need to find $\sin(\alpha + \beta)$.

Step 3: Using the angle addition formula for sine, we have:
$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$

Step 4: Let's find $\sin\alpha$, $\cos\alpha$, $\sin\beta$, and $\cos\beta$.

Step 5: For $\alpha = \tan^{-1}\frac{1}{2}$, we have $\tan\alpha = \frac{1}{2}$. Using the Pythagorean identity, we get:
$\sin^2\alpha + \cos^2\alpha = 1$
$\tan^2\alpha = \frac{\sin^2\alpha}{\cos^2\alpha}$
$\frac{1}{4} = \frac{\sin^2\alpha}{\cos^2\alpha}$
$\sin^2\alpha = \frac{1}{4}\cos^2\alpha$

Substituting this into the Pythagorean identity, we get:
$\frac{1}{4}\cos^2\alpha + \cos^2\alpha = 1$
$\frac{5}{4}\cos^2\alpha = 1$
$\cos^2\alpha = \frac{4}{5}$
$\cos\alpha = \frac{2}{\sqrt{5}}$ (since $\alpha$ is in the first quadrant)

Now, $\sin\alpha = \tan\alpha\cos\alpha = \frac{1}{2} \cdot \frac{2}{\sqrt{5}} = \frac{1}{\sqrt{5}}$.

Step 6: For $\beta = \cot^{-1}2$, we have $\cot\beta = 2$. Using the Pythagorean identity, we get:
$\sin^2\beta + \cos^2\beta = 1$
$\cot^2\beta = \frac{\cos^2\beta}{\sin^2\beta}$
$4 = \frac{\cos^2\beta}{\sin^2\beta}$
$\cos^2\beta = 4\sin^2\beta$

Substituting this into the Pythagorean identity, we get:
$\sin^2\beta + 4\sin^2\beta = 1$
$5\sin^2\beta = 1$
$\sin^2\beta = \frac{1}{5}$
$\sin\beta = \frac{1}{\sqrt{5}}$ (since $\beta$ is in the first quadrant)

Now, $\cos\beta = \sin\beta\cot\beta = \frac{1}{\sqrt{5}} \cdot 2 = \frac{2}{\sqrt{5}}$.

Step 7: Substituting these values into the angle addition formula, we get:
$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$
$= \frac{1}{\sqrt{5}} \cdot \frac{2}{\sqrt{5}} + \frac{2}{\sqrt{5}} \cdot \frac{1}{\sqrt{5}}$
$= \frac{2}{5} + \frac{2}{5}$
$= \frac{4}{5}$

Therefore, the value of $\sin(\tan^{-1}\frac{1}{2} + \cot^{-1}2)$ is $\frac{4}{5}$.
