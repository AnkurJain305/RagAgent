# Calculus: Differentiation

## Basic Differentiation Rules

1. **Constant Rule**: If $f(x) = c$ where $c$ is a constant, then $f'(x) = 0$

2. **Power Rule**: If $f(x) = x^n$ where $n$ is a real number, then $f'(x) = nx^{n-1}$

3. **Constant Multiple Rule**: If $f(x) = c \cdot g(x)$ where $c$ is a constant, then $f'(x) = c \cdot g'(x)$

4. **Sum Rule**: If $f(x) = g(x) + h(x)$, then $f'(x) = g'(x) + h'(x)$

5. **Difference Rule**: If $f(x) = g(x) - h(x)$, then $f'(x) = g'(x) - h'(x)$

6. **Product Rule**: If $f(x) = g(x) \cdot h(x)$, then $f'(x) = g'(x) \cdot h(x) + g(x) \cdot h'(x)$

7. **Quotient Rule**: If $f(x) = \frac{g(x)}{h(x)}$, then $f'(x) = \frac{g'(x) \cdot h(x) - g(x) \cdot h'(x)}{[h(x)]^2}$

8. **Chain Rule**: If $f(x) = g(h(x))$, then $f'(x) = g'(h(x)) \cdot h'(x)$

## Derivatives of Common Functions

1. $\frac{d}{dx}(\sin x) = \cos x$

2. $\frac{d}{dx}(\cos x) = -\sin x$

3. $\frac{d}{dx}(\tan x) = \sec^2 x$

4. $\frac{d}{dx}(e^x) = e^x$

5. $\frac{d}{dx}(\ln x) = \frac{1}{x}$

6. $\frac{d}{dx}(a^x) = a^x \ln a$

7. $\frac{d}{dx}(\log_a x) = \frac{1}{x \ln a}$

## Applications of Derivatives

### Finding Rate of Change

The derivative $f'(x)$ represents the rate of change of $f(x)$ with respect to $x$. In physical terms, if $s(t)$ represents the position of an object at time $t$, then:

- $v(t) = s'(t)$ is the velocity (rate of change of position)
- $a(t) = v'(t) = s''(t)$ is the acceleration (rate of change of velocity)

### Finding Maxima and Minima

To find the local maxima and minima of a function $f(x)$:

1. Find the critical points by solving $f'(x) = 0$
2. Use the second derivative test:
   - If $f''(x) < 0$ at a critical point, it's a local maximum
   - If $f''(x) > 0$ at a critical point, it's a local minimum
   - If $f''(x) = 0$, the test is inconclusive

### Finding Points of Inflection

Points of inflection occur where the concavity of a function changes. To find them:

1. Solve $f''(x) = 0$
2. Check if $f''(x)$ changes sign around these points

## Common JEE Problems

### Problem 1: Finding the Equation of a Tangent Line

To find the equation of the tangent line to a curve $y = f(x)$ at a point $(a, f(a))$:

1. Calculate the derivative $f'(x)$
2. Evaluate $f'(a)$ to find the slope of the tangent line
3. Use the point-slope form: $y - f(a) = f'(a)(x - a)$

### Problem 2: Related Rates

When two or more related quantities are changing with time, we can use the chain rule to relate their rates of change.

Example: If a spherical balloon is being inflated at a rate of $3$ cm³/s, how fast is the radius increasing when the radius is $5$ cm?

Solution:
- Volume of a sphere: $V = \frac{4}{3}\pi r^3$
- Differentiating with respect to time: $\frac{dV}{dt} = 4\pi r^2 \frac{dr}{dt}$
- Given: $\frac{dV}{dt} = 3$ cm³/s, $r = 5$ cm
- Solving for $\frac{dr}{dt}$: $\frac{dr}{dt} = \frac{3}{4\pi r^2} = \frac{3}{4\pi \cdot 25} = \frac{3}{100\pi}$ cm/s

### Problem 3: Optimization

Many JEE problems involve finding the maximum or minimum value of a quantity.

Example: Find the dimensions of a rectangle with perimeter $P$ that has the maximum area.

Solution:
- Let the length be $x$ and width be $y$
- Perimeter: $2x + 2y = P$, so $y = \frac{P - 2x}{2}$
- Area: $A = xy = x \cdot \frac{P - 2x}{2} = \frac{Px - 2x^2}{2}$
- To maximize area, find where $\frac{dA}{dx} = 0$:
  $\frac{dA}{dx} = \frac{P - 4x}{2} = 0$
  $P - 4x = 0$
  $x = \frac{P}{4}$
- Since $y = \frac{P - 2x}{2} = \frac{P - 2(\frac{P}{4})}{2} = \frac{P}{4}$
- Therefore, the rectangle with maximum area is a square with $x = y = \frac{P}{4}$

## Important Theorems

### Mean Value Theorem

If a function $f(x)$ is continuous on the closed interval $[a, b]$ and differentiable on the open interval $(a, b)$, then there exists at least one point $c$ in $(a, b)$ such that:

$$f'(c) = \frac{f(b) - f(a)}{b - a}$$

### Rolle's Theorem

If a function $f(x)$ is continuous on the closed interval $[a, b]$ and differentiable on the open interval $(a, b)$, and if $f(a) = f(b)$, then there exists at least one point $c$ in $(a, b)$ such that $f'(c) = 0$.

### L'Hôpital's Rule

If $\lim_{x \to a} \frac{f(x)}{g(x)}$ gives the indeterminate form $\frac{0}{0}$ or $\frac{\infty}{\infty}$, then:

$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

provided the limit on the right exists or is infinite.
